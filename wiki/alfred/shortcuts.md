# Alfred 快捷键大全

> 本文档整理 Alfred 的所有快捷键，方便快速查阅。

## 🎯 核心快捷键

### 启动和导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `F19` | 启动 Alfred | 当前配置 |
| `⌘ + ,` | 打开偏好设置 | 在 Alfred 窗口中 |
| `⌘ + ?` | 显示帮助 | 在 Alfred 窗口中 |
| `Esc` | 关闭 Alfred | 随时关闭 |
| `Enter` | 执行选中项 | 确认操作 |
| `⌘ + Enter` | 在 Finder 中打开 | 打开文件位置 |

### 结果导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` / `↓` | 上下导航 | 选择结果 |
| `←` / `→` | 左右导航 | 展开/折叠 |
| `Enter` | 执行 | 执行选中项 |
| `⌘ + 数字` | 快速选择 | 选择第 N 个结果 |

## 📋 剪贴板历史

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `⌘ + ⌥ + C` | 打开剪贴板历史 | 需要先启用 |
| `↑` / `↓` | 导航历史 | 选择历史记录 |
| `Enter` | 粘贴选中项 | 粘贴到当前应用 |
| `⌘ + C` | 复制选中项 | 复制到剪贴板 |
| `Delete` | 删除选中项 | 从历史中删除 |
| `⌘ + Delete` | 清空历史 | 清空所有历史 |

## 📝 自定义快捷键

### 修改启动快捷键

```
Alfred Preferences → General → Alfred Hotkey
点击当前快捷键 → 按下新的快捷键组合
```

**推荐配置**：
- `F19`（当前配置）
- `⌘ + ⌥ + Space`（推荐）
- `⌘ + Space`（需禁用 Spotlight）

### 设置工作流快捷键

```
Alfred Preferences → Workflows → 选择工作流
+ → Hotkey → 设置快捷键
```

## 🎯 与其他工具的快捷键配合

### 与 Ghostty 配合

| 场景 | Alfred | Ghostty |
|------|--------|---------|
| 打开终端 | `F19` → `ghostty` → `Enter` | `⌥ + Space`（Quick Terminal） |
| 新建标签 | - | `⌘ + T` |
| 切换标签 | - | `⌘ + Shift + [` / `]` |

|------|--------|---------|

| 打开文件 | `F19` → `find 文件名` | `⌘ + P` |
