# Alfred 使用指南

> **Alfred** 是 macOS 上最强大的效率工具之一，可以看作是 Spotlight 的超级增强版。
> 本文档记录 Alfred 的使用方法、快捷键、工作流等内容。

## 📋 概述

Alfred 是一款 macOS 效率启动器，提供以下核心功能：

- **快速启动** — 启动应用程序、打开文件
- **Web 搜索** — 快速搜索 Google、GitHub 等
- **剪贴板历史** — 记录复制过的内容
- **片段替换** — 快速插入常用文本
- **系统命令** — 锁屏、休眠、清空废纸篓等
- **工作流（Workflow）** — 自动化复杂任务

## 🚀 快速开始

### 当前配置

| 配置项 | 设置 |
|--------|------|
| 启动快捷键 | `F19` |
| 剪贴板历史 | 已启用 |
| 片段 | 未配置 |
| 工作流 | 无自定义 |

### 基础操作

```
F19 → 输入内容 → Enter
```
