# K线图（蜡烛图）

## 概述

K线图（又称日本蜡烛图）是展示金融资产价格走势的图表方法，起源于18世纪日本的大米交易商本间宗久。1991年史蒂夫·尼森将其引入西方金融市场。

每根 K 线包含四个价格：**开盘价、收盘价、最高价、最低价**。

## K线结构

```
    │  ← 上影线（最高价）
  ┌───┐
  │   │  ← 实体（开盘价与收盘价之间）
  │   │
  └───┘
    │  ← 下影线（最低价）
```

- **阳线（红色/空心）**：收盘价 > 开盘价（A股惯例，国际上常用绿色）
- **阴线（绿色/实心）**：收盘价 < 开盘价（A股惯例，国际上常用红色）
- **实体**：开盘价与收盘价之间的区域
- **影线**：最高价和最低价超出实体的部分

## 单根K线形态

### 关键形态速查

| 形态 | 特征 | 信号 |
|-----|------|-----|
| **大阳线** | 实体长，影线短 | 强烈看涨 |
| **大阴线** | 实体长，影线短 | 强烈看跌 |
| **十字星** | 实体极小，上下影线 | 多空平衡，可能反转 |
| **锤子线** | 下影线长（≥实体2倍），无上影线 | 底部反转（看涨） |
| **上吊线** | 同锤子线，但出现在高位 | 顶部反转（看跌） |
| **倒锤子** | 上影线长，下影线短或无 | 底部反转 |
| **射击之星** | 同倒锤子，但出现在高位 | 顶部反转 |
| **一字线** | 四价合一 | 极端行情（涨停/跌停） |

## 组合K线形态

### 反转信号

| 形态 | 构成 | 信号 |
|-----|------|-----|
| **早晨之星** | 大阴 + 小实体/十字 + 大阳 | 底部反转看涨 |
| **黄昏之星** | 大阳 + 小实体/十字 + 大阴 | 顶部反转看跌 |
| **乌云盖顶** | 大阳 + 高开但收盘深入前阳实体 | 顶部反转 |
| **刺透形态** | 大阴 + 低开但收盘深入前阴实体 | 底部反转 |
| **吞没形态** | 后一根实体完全包含前一根实体 | 强烈反转信号 |
| **三只乌鸦** | 连续三根阴线，依次创新低 | 顶部反转 |
| **红三兵** | 连续三根阳线，依次创新高 | 底部反转 |

### 持续信号

| 形态 | 构成 | 信号 |
|-----|------|-----|
| **上升三法** | 大阳 + 小阴回踩 + 大阳突破 | 上升趋势延续 |
| **下降三法** | 大阴 + 小阳反弹 + 大阴突破 | 下降趋势延续 |

## K线分析要点

1. **结合位置判断**：同样的 K 线形态在不同位置意义完全不同
2. **结合成交量**：放量突破比缩量突破更可靠
3. **结合趋势**：顺趋势的信号比逆趋势的更有效
4. **多重验证**：不要仅凭单一 K 线形态下单

## Heikin-Ashi（平均K线）

一种平滑价格数据的 K 线变体：
- 使用加权平均计算开盘价和收盘价
- 过滤掉市场噪音，更清晰地显示趋势
- 适合趋势跟踪，但会损失精确的价格信息

## 实用建议

- K线分析是[[技术分析]]的核心工具之一
- 单独使用 K 线形态的胜率约 50-60%
- 结合均线（MA）、成交量等指标可提高胜率
- 不同时间周期的 K 线信号优先级：周线 > 日线 > 60分钟 > 15分钟
