# 股票投资入门

## 学习路线图

```
阶段一：基础概念 → 阶段二：分析方法 → 阶段三：实战策略 → 阶段四：进阶提升
```

## 阶段一：核心基础概念

### 什么是股票
股票代表公司**所有权份额**。买入股票即成为公司股东，享有：
- **分红权**：公司盈利时按持股比例分配利润
- **投票权**：参与公司重大决策
- **资本增值**：股价上涨带来的收益

### 股票市场结构

| 市场 | 说明 |
|-----|------|
| **A 股** | 中国大陆上市公司股票（上交所、深交所） |
| **港股** | 香港联交所上市股票 |
| **美股** | 美国上市公司股票（NYSE、NASDAQ） |

### 基本术语
- **市盈率（PE）**：股价 / 每股收益，衡量估值高低
- **市净率（PB）**：股价 / 每股净资产
- **股息率**：年分红 / 股价
- **市值**：股价 × 总股本
- **换手率**：成交量 / 流通股本，反映交易活跃度
- **涨停/跌停**：A 股主板涨跌幅限制 ±10%，创业板/科创板 ±20%

## 阶段二：分析方法

### 基本面分析
详见 → [[基本面分析]]

核心问题：**这家公司值多少钱？**

- 阅读财务报表（资产负债表、利润表、现金流量表）
- 分析财务比率（ROE、毛利率、资产负债率）
- 评估行业地位和竞争优势（护城河）
- 使用 DCF（现金流折现）估算内在价值

### 技术分析
详见 → [[技术分析]]

核心问题：**价格下一步往哪走？**

- 学习 [[K线图]] 读法
- 掌握均线（MA）、MACD、RSI 等指标
- 识别趋势线、支撑位和阻力位
- 理解成交量与价格的关系

## 阶段三：实战策略

### 主要投资风格

| 风格 | 持仓周期 | 核心逻辑 | 代表人物 |
|-----|---------|---------|---------|
| **价值投资** | 数年 | 买入被低估的好公司 | 巴菲特、格雷厄姆 |
| **成长投资** | 数月~数年 | 投资高增长公司 | 彼得·林奇 |
| **趋势交易** | 数天~数月 | 顺势而为 | 威廉·欧奈尔 |
| **短线交易** | 数小时~数天 | 利用短期波动 | — |

### 关键原则

1. **永远不要用生活必需资金投资**
2. **分散投资**：不把鸡蛋放在一个篮子里 → [[投资组合理论]]
3. **止损纪律**：设定并严格执行止损点
4. **持续学习**：市场在变化，知识需更新
5. **控制情绪**：贪婪和恐惧是最大的敌人

## 推荐学习资源

### 经典书籍
1. 《聪明的投资者》 — 本杰明·格雷厄姆（价值投资圣经）
2. 《股票大作手回忆录》 — 埃德温·勒菲弗（交易心理）
3. 《漫步华尔街》 — 伯顿·马尔基尔（投资理论入门）
4. 《日本蜡烛图技术》 — 史蒂夫·尼森（K线分析经典）
5. 《期货市场技术分析》 — 约翰·墨菲（技术分析大全）

### 实践平台
- **模拟交易**：先用模拟账户练习，熟悉交易流程
- **雪球（Xueqiu）**：中国投资者社区，跟踪市场热点
- **东方财富/同花顺**：行情软件，基本面+技术面数据
