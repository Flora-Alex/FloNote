# 基本面分析

## 定义

基本面分析是通过评估**公司财务状况、行业前景和宏观经济环境**来确定资产内在价值的分析方法。核心目标：判断当前价格是否高于或低于其[[内在价值]]，从而做出买卖决策。

> 如果内在价值 > 市场价格 → 买入（被低估）
> 如果内在价值 < 市场价格 → 卖出（被高估）

## 分析框架

### 自上而下（Top-Down）
```
宏观经济 → 行业分析 → 公司筛选
```
1. 分析 GDP、通胀率、利率、货币政策
2. 选择受益于宏观趋势的行业
3. 在行业中挑选优质公司

### 自下而上（Bottom-Up）
```
公司分析 → 对标比较 → 估值判断
```
直接分析个别公司的财务数据和竞争优势，不受宏观判断约束。

## 三张财务报表

### 资产负债表（Balance Sheet）
**公式：资产 = 负债 + 股东权益**

反映公司在某一时间点的财务状况：
- **资产**：现金、应收账款、存货、固定资产等
- **负债**：短期借款、长期借款、应付账款等
- **股东权益**：实收资本、留存收益

### 利润表（Income Statement）
反映公司在一定期间内的经营成果：
- **营业收入** → 减去成本和费用 → **净利润**
- 关注：营收增长率、毛利率、净利率

### 现金流量表（Cash Flow Statement）
反映公司现金的流入和流出：
- **经营活动现金流**：核心业务产生的现金（最重要！）
- **投资活动现金流**：购买/出售资产
- **筹资活动现金流**：借款、还款、分红

> 💡 **关键原则**：利润可以被操纵，但现金流不会说谎。优秀的公司经营性现金流应持续为正。

## 核心财务比率

### 盈利能力
| 指标 | 公式 | 意义 |
|-----|------|-----|
| **毛利率** | (营收-成本) / 营收 | 产品竞争力 |
| **净利率** | 净利润 / 营收 | 整体盈利能力 |
| **ROE（净资产收益率）** | 净利润 / 股东权益 | 股东回报率，>15% 为优秀 |
| **ROA（总资产收益率）** | 净利润 / 总资产 | 资产利用效率 |

### 估值指标
| 指标 | 公式 | 意义 |
|-----|------|-----|
| **PE（市盈率）** | 股价 / EPS | 回本年数，越低越便宜 |
| **PB（市净率）** | 股价 / 每股净资产 | 资产溢价程度 |
| **PEG** | PE / 盈利增长率 | 考虑成长性的估值 |
| **PS（市销率）** | 市值 / 营收 | 适用于亏损公司 |

### 财务健康
| 指标 | 公式 | 意义 |
|-----|------|-----|
| **资产负债率** | 总负债 / 总资产 | 杠杆水平，>70% 需警惕 |
| **流动比率** | 流动资产 / 流动负债 | 短期偿债能力，>2 较好 |
| **利息保障倍数** | EBIT / 利息支出 | 偿付利息的能力 |

## 估值方法

### 现金流折现（DCF）
**核心思想**：一家公司的价值等于其未来所有自由现金流的现值之和。

```
内在价值 = Σ (未来自由现金流 / (1 + 折现率)^n)
```

- 需要预测未来现金流和确定折现率（通常用 WACC）
- 对假设高度敏感，微小变化会导致结果大不同
- 适合现金流稳定的成熟公司

### 相对估值法
将公司与同行业可比公司的估值指标进行对比：
- PE 对比法
- PB 对比法
- EV/EBITDA 对比法

### 股利折现模型（DDM）
适合稳定分红的公司：
```
股价 = 下一期股息 / (必要收益率 - 股息增长率)
```

## 护城河分析（竞争优势）

沃伦·巴菲特提出的概念，好的公司应具备持久的竞争优势：

1. **品牌护城河**：品牌溢价（如茅台、苹果）
2. **成本护城河**：规模效应带来的低成本（如沃尔玛）
3. **网络效应护城河**：用户越多价值越大（如微信）
4. **转换成本护城河**：用户迁移成本高（如企业软件）
5. **专利/牌照护城河**：法律保护的独占权

## 常见陷阱

- **价值陷阱**：看似便宜的股票可能因为基本面恶化而持续下跌
- **增长幻觉**：高增长不可持续时，估值会大幅缩水
- **忽视现金流**：利润高但现金流差的公司风险大
- **过度依赖单一指标**：应综合多个指标判断
